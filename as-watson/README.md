# A S Watson — Client Opportunity Workspace

Workspace for turning a completed business travel trip into next-step planning for **A S Watson**.

## How to use

1. **Travel summary in** — paste or fill out the trip details in [`travel-summary.md`](travel-summary.md).
2. **Planning conversation on top** — use [`notes/planning.md`](notes/planning.md) to capture discussion with AI about follow-ups, opportunity angles, and proposed next steps for A S Watson.

No code or agents live here — just the trip context and the planning thread.
